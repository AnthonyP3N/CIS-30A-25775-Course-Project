# CIS-30A-25775-Course-Project
This project is a personal finance tracking tool developed in Python, designed to help users visualize their spending habits and manage their budgets effectively. It features a user-friendly graphical interface (GUI) that allows users to enter transactions manually or import financial data directly from CSV files. The tool categorizes expenses, calculates remaining balances in relation to total income, and provides real-time alerts to help users avoid overspending.
